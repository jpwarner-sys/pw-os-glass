Joe workshop folders are not the cabinet.

## URL

After GitHub Pages is on for `jpwarner-sys/pw-os-glass`:

`https://jpwarner-sys.github.io/pw-os-glass/`

**Recommendation:** For isolation from other apps on the shared `github.io` origin (like Joe OS glass), you can serve this from `glass.ontologyhome.ca/pw` (or similar). No DNS changes are strictly required, but it prevents `localStorage` and Service Worker cache collisions.

Paste that over `[GLASS_URL]` in `START_HERE.md`.

`?demo=1` wakes on fixture files so you can see tiles without his Drive. Do not send the owner that query.

## Bind

Night one the glass stays black until files exist **and** this page is bound.

- **Folder** — Chrome / Edge on the Mac. He points at the local Drive-synced `PW_OS` folder. Dump writes `dump/YYYY-MM-DDTHHMMSSZ.md`.
- **Drive** — needs a Google Cloud OAuth client id in `config.js` (`GOOGLE_CLIENT_ID`). Authorized origin = this Pages URL. Scopes: `drive.readonly` + `drive.file`. Without the id the Drive control stays dark.

Phone stays a slot until Drive OAuth is filled. That matches VESSELS.
